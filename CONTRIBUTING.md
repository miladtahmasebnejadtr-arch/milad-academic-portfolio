# Contributing

This repository is maintained as a personal academic portfolio and GitHub learning project.

## Scope

Acceptable contributions may include:

- Documentation improvements
- Markdown formatting corrections
- Suggestions for better repository organization
- Academic profile improvements

## Guidelines

- Use clear and concise language
- Do not add private or sensitive information
- Do not add raw research data without permission
- Use meaningful commit messages
- Keep files organized by topic

## Commit Message Examples

Good examples:

- Improve README structure
- Add research interests document
- Fix Markdown formatting
- Update academic background

Poor examples:

- update
- test
- changes
